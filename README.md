# tidytree: A Tidy Tool for Phylogenetic Tree Data Manipulation

[![CRAN_Status_Badge](https://www.r-pkg.org/badges/version/tidytree?color=green)](https://cran.r-project.org/package=tidytree)

[![](https://cranlogs.r-pkg.org/badges/last-week/tidytree?color=green)](https://cranlogs.r-pkg.org/downloads/total/last-week/tidytree)

Phylogenetic trees contain components such as nodes, edges, branches,
and associated data. As the core data manipulation tool in the ‘ggtree’
ecosystem, ‘tidytree’ provides tools for converting tree objects to tidy
data frames and tidy interfaces for manipulating, analyzing, and
visualizing tree data.

Visit <https://yulab-smu.top/treedata-book-2ed/> for details.
